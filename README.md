# machine-learning-practice-projects
A collection of six hands-on Machine Learning practice projects using Python and scikit-learn, covering supervised and unsupervised learning, data preprocessing, model training, evaluation, and clustering.

# Machine Learning Practice Projects

This repository contains six practice projects developed while learning Machine Learning with Python.

## Topics Covered

- **Supervised Learning:** Training models using labeled datasets for prediction and classification.
- **Unsupervised Learning:** Discovering patterns, clusters, and structures in unlabeled datasets.
- **Data Preprocessing:** Preparing datasets for Machine Learning.
- **Model Training and Evaluation:** Training models and evaluating their performance using appropriate metrics.

## Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Structure

Each project is organized in its own folder and includes the relevant notebook, dataset (where permitted), and analysis.

## Purpose

The purpose of this repository is to practise Machine Learning algorithms, strengthen my understanding of supervised and unsupervised learning, and document my progress toward becoming a Data Scientist / Machine Learning Engineer.
